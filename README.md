# سجل الصوب — Greenhouse Crop & IPM

تطبيق ويب تقدمي (PWA) للتابلت الميداني: تسجيل نمو المحصول الأسبوعي وحساب توازن النبات (خضري ↔ ثمري)، ويعمل بالكامل بدون إنترنت داخل الصوبة ويزامن تلقائيًا مع Supabase.

## ما يعمل الآن (الإصدار 0.4)

## البنية

```
src/
  lib/
    schema.ts        تعريف الأعمدة القابلة للكتابة وترتيب الرفع (مطابق لقاعدة البيانات — scripts/check-schema.mjs)
    db.ts            قاعدة البيانات المحلية (IndexedDB / Dexie)
    repo.ts          كل الكتابة المحلية: قيم افتراضية + تعليم للرفع + أعمدة مشتقة
    sync.ts          محرك المزامنة
    balance.ts       حساب التوازن — نفس منطق v_crop_weekly_summary
    ipm.ts           ضغط الآفات، فترة الأمان، تكرار مجموعات المقاومة — نفس منطق views السيرفر
    photos.ts        ضغط الصور وحفظها على الجهاز ورفعها قبل سجلها
  screens/           الشاشات
  components/        المكونات المشتركة
supabase/
  migrations/        001–008 (مطبّقة على المشروع)
  functions/team-admin  إنشاء حسابات الفريق (Edge Function)
e2e/                 اختبار شامل على نسخة محلية من Supabase (Postgres + PostgREST + مصادقة محاكاة)
```

### المزامنة
- **الرفع:** السجلات المعلّمة تُرفع بالترتيب (الأب قبل الابن) عبر `upsert`. لو الدفعة رُفضت، يُرفع سجل سجل لعزل المرفوض وحده مع سبب عربي واضح.
- **السحب:** لكل جدول ما تغيّر بعد آخر `server_updated_at` بهامش دقيقتين، بترقيم keyset. السجل المحلي غير المرفوع لا يُستبدل.
- **الأعطال المؤقتة:** إعادة محاولة تلقائية متدرجة (3، 10، 30، 60 ثانية).
- **ساعة الجهاز:** تُقارن بوقت السيرفر ويظهر تنبيه لو الفرق أكثر من 10 دقائق.

## التشغيل

```bash
npm ci
npm run dev          # تطوير
npm test             # اختبارات الوحدات
npm run build        # بناء الإنتاج (dist/)
```

### الاختبار الشامل (E2E)
يحتاج PostgreSQL 16 وPostgREST وChromium:
```bash
./e2e/build.sh && ./e2e/setup.sh && node e2e/run.mjs
```
يغطي (57 فحص): الدخول، تجهيز صوبة ودورة و8 نباتات وقيم مستهدفة، تسجيل 7 نباتات بدون إنترنت، إعادة فتح التطبيق أوفلاين، المزامنة، مطابقة حكم التوازن مع السيرفر، مهندس ثانٍ على جهاز آخر، رفض تعديل غير مصرح به وعرض السبب، جولة فحص بدون إنترنت بصورة ورفعها، توصية من الملاحظة وتنفيذها برش وإغلاقها على السيرفر، فترة الأمان وتحذير المقاومة، لوحة المتابعة، وعدم وجود تمرير أفقي على الموبايل في كل الشاشات.
